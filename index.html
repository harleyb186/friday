FRIDAY

FRIDAY is a private, personal assistant used by a single individual (Harley Bush) to manage their own email and calendar. It is not offered to the public.

Privacy Policy

Last updated: October 31, 2026

What FRIDAY accesses. With the account owner's explicit permission via Google sign-in, FRIDAY reads, labels, organizes and (only when asked) sends Gmail messages, and reads and manages Google Calendar events for that owner's own accounts.

How data is used. Data is used solely to provide personal assistant features to the account owner, such as inbox summaries, reminders and schedule management. It is not sold, rented, shared with third parties, or used for advertising.

Storage. Access tokens are stored locally on the owner's own computer in the system keychain. FRIDAY does not maintain a separate server database of Google user data.

Google API Services. FRIDAY's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.
